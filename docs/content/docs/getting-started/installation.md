## Maven

Add the dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>dev.agiro</groupId>
  <artifactId>criteria-filter</artifactId>
  <version>{{< param version >}}</version>
</dependency>
```

## Gradle

```groovy
implementation 'dev.agiro:criteria-filter:{{< param version >}}'
```

## Requirements

- Java 21 or later
- Spring Boot 3.3.x
